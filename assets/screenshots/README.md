# Screenshot provenance

Only real screenshots with a verified version and a separate demonstration profile belong here. Do not include personal paths, history, accounts, clipboard data or private media.

Screenshots of an unpublished build must be explicitly labelled **Preview** and shown separately from the currently downloadable release. A screenshot of public 0.1.3 must come from the public 0.1.3 binary, not a newer build with the same version number.

The `preview-0.1.4-*.jpg` files are unedited captures of the native Windows app on 1 October 2026. The separate empty demonstration profile used English/Russian, dark mode, Graphite and Purple. The settings captures display version 0.1.4. The home capture belongs to the same session. No personal media or accounts were loaded. The three captures linked from the landing pages show no personal filesystem paths.
